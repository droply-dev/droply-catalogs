# Datenschutzerklärung für Drōply

Die App "Drōply" (com.leanderfischer.droply) wurde als datenschutzfreundliche Anwendung entwickelt.

## 1. Verantwortlicher für die Datenverarbeitung
Verantwortlich für das Angebot dieser App ist der Inhaber des Apple-Entwicklerkontos:
Volker Fischer

E-Mail: feedback.droply@gmail.com

## 2. Lokale Speicherung (Offline-First)
Alle von Ihnen in der App eingegebenen Daten (wie Kundendaten, Notizen, Rezepte und Bestellpläne) werden ausschließlich lokal auf Ihrem Endgerät gespeichert (mittels AsyncStorage). Es findet keine Synchronisation mit einer Cloud oder externen Datenbanken statt.

## 3. Abruf von externen Inhalten (Katalog-Import & Bilder)
Die App ermöglicht es Nutzern, Produktkataloge über selbst bereitgestellte, externe URLs (z. B. GitHub) zu importieren. 
* **Netzwerkanfragen:** Beim Import eines Katalogs und beim Anzeigen von Produktbildern, die über URLs im Katalog hinterlegt sind, baut die App eine direkte Verbindung zum jeweiligen externen Server (z. B. GitHub oder dem Bild-Hoster) auf, um die Daten zu laden.
* **Protokolldaten:** Bei diesen technisch notwendigen Abrufen werden IP-Adresse und Gerätedaten an den jeweiligen Server-Betreiber übermittelt. Der App-Betreiber selbst erfasst, speichert oder wertet diese Daten nicht aus.

## 4. Datenweitergabe an Dritte
Abgesehen von den technisch notwendigen Netzwerkanfragen zum Laden der von Ihnen angegebenen URLs findet keinerlei Weitergabe von Daten an Dritte statt. Die volle Kontrolle über alle eingegebenen Daten verbleibt auf Ihrem Gerät.

## 5. Rechte der Nutzer
Da alle Anwendungsdaten ausschließlich lokal auf Ihrem Gerät liegen, können Sie diese jederzeit selbstständig und vollständig löschen, indem Sie die App deinstallieren oder die App-Daten in den Einstellungen Ihres Betriebssystems leeren.
